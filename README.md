# Chronicles of the Architect: Boss Rush

2D turn-based RPG Boss Rush.

**Play:** open `index.html` in any modern browser (desktop or mobile).

## Features
- 3 heroes: Forge, Itap, Tango
- 10 sequential bosses with unique mechanics
- Timing attack/defense minigame
- Character synergies
- Story mode + save/continue (localStorage)
- Leveling + passive upgrades
- Polished HUD and visual effects

## Controls
- Click/tap action buttons
- Timing bar: tap when the white marker hits the green zone (yellow = Perfect)
